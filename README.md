# 沪深A股数据查询系统 - 使用说明

## 📖 系统概述

这是一个基于Python和tkinter开发的沪深A股数据查询系统，提供了现代化的用户界面和丰富的数据查询、可视化功能。

## 🚀 快速开始

### 环境要求

- Python 3.7+
- Windows操作系统
- QMT交易软件（用于数据获取）

### 依赖项安装

```bash
# 安装必要依赖
pip install pandas duckdb

# 安装可选依赖（用于图表和Excel导出）
pip install matplotlib openpyxl

# 注意：xtquant模块需要QMT软件支持
```

### 启动方法

#### 方法1：使用启动脚本（推荐）
```bash
python run_gui.py
```

#### 方法2：直接运行GUI文件
```bash
# 完整版（包含图表功能）
python stock_gui_improved.py

# 简化版（不依赖matplotlib）
python stock_gui_simple.py
```

## 📋 功能特性

### 🔍 数据查询
- **股票代码查询**：支持输入股票代码（如：000001.SZ）
- **日期范围选择**：自定义查询开始和结束日期
- **复权方式**：支持前复权、后复权、等比复权等多种方式
- **实时查询**：快速从本地数据库查询历史数据

### 📊 数据显示
- **表格显示**：清晰展示开盘价、收盘价、最高价、最低价、成交量等
- **涨跌标识**：红绿颜色区分涨跌
- **统计信息**：显示期间涨跌幅、最高价、最低价、平均成交量等
- **排序功能**：支持按各列排序

### 📈 图表功能（完整版）
- **K线图**：标准蜡烛图显示
- **折线图**：收盘价走势
- **OHLC图**：开高低收图
- **成交量图**：成交量柱状图
- **移动平均线**：支持自定义周期（5日、10日、20日等）

### 💾 数据导出
- **CSV格式**：通用表格格式
- **Excel格式**：支持.xlsx格式
- **选择性导出**：可导出全部数据或选中行
- **剪贴板复制**：快速复制单行数据

### 🔄 数据更新
- **增量更新**：只下载新增数据，提高效率
- **全量下载**：下载所有A股历史数据
- **多线程下载**：支持并发下载，提高速度
- **进度显示**：实时显示下载进度

## 🔧 使用流程

### 1. 首次使用
1. 确保QMT软件已启动
2. 运行 `python run_gui.py`
3. 点击"下载所有A股"获取基础数据
4. 等待下载完成（可能需要较长时间）

### 2. 日常查询
1. 输入股票代码（如：000001.SZ）
2. 选择日期范围
3. 选择复权方式
4. 点击"查询数据"

### 3. 数据更新
1. 点击"增量更新"更新已有数据
2. 或定期运行"下载所有A股"获取最新数据

## ⚠️ 注意事项

1. **QMT依赖**：数据获取需要QMT软件运行
2. **网络连接**：下载数据需要稳定的网络连接
3. **磁盘空间**：所有A股数据可能占用数GB空间
4. **数据时效性**：建议每日更新数据
5. **复权说明**：
   - 前复权：以当前价格为基准调整历史价格
   - 后复权：以历史价格为基准调整当前价格
   - 等比复权：保持价格比例关系

## 🐛 常见问题

### Q: 启动时提示"数据库连接失败"
A: 确保QMT软件已启动，并且xtquant模块可用

### Q: 查询不到数据
A: 
1. 检查股票代码格式是否正确（如：000001.SZ）
2. 确认已下载该股票的数据
3. 检查日期范围是否合理

### Q: 图表不显示
A: 
1. 确保安装了matplotlib：`pip install matplotlib`
2. 使用完整版GUI：`python stock_gui_improved.py`

### Q: 下载速度慢
A: 
1. 检查网络连接
2. 调整并发线程数（在代码中修改max_workers参数）
3. 分批下载，避免一次性下载过多数据

## 🎨 颜色自定义

### 预设颜色主题
系统提供5种预设颜色主题：
- **绿色主题**：默认主题，清新自然
- **蓝色主题**：专业稳重
- **紫色主题**：优雅神秘
- **橙色主题**：活力温暖
- **红色主题**：热情醒目

### 更改按钮颜色

#### 方法1：使用颜色选择器（推荐）
```bash
python color_chooser.py
```
运行颜色选择器，可以预览不同颜色效果，一键应用。

#### 方法2：修改配置文件
编辑 [`color_config.py`](color_config.py:1) 文件中的 `DEFAULT_SCHEME` 变量：
```python
# 改为其他颜色主题
DEFAULT_SCHEME = 'blue'  # 蓝色主题
DEFAULT_SCHEME = 'purple'  # 紫色主题
DEFAULT_SCHEME = 'orange'  # 橙色主题
DEFAULT_SCHEME = 'red'  # 红色主题
```

#### 方法3：自定义颜色
在 [`color_config.py`](color_config.py:1) 中添加自定义颜色方案：
```python
'custom': {
    'name': '自定义主题',
    'button_bg': '#FF6B6B',      # 按钮背景色
    'button_active': '#FF5252',   # 按钮激活色
    'button_pressed': '#FF3838',  # 按钮按下色
    'select_bg': '#0078d4',       # 选择背景色
    'bg': '#f0f0f0',             # 界面背景色
    'fg': '#333333'               # 文字颜色
}
```

- [`color_config.py`](color_config.py:1) - 颜色配置文件
- [`color_chooser.py`](color_chooser.py:1) - 颜色选择器工具
